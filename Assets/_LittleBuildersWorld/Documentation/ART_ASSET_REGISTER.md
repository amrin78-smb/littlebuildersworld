# Art & Asset Register — Little Builders World

Everything is **original and generated by code** in `Assets/_LittleBuildersWorld/Scripts/Editor` (re-running
Setup reproduces it), except the font and Unity's own TextMeshPro essentials. No downloaded models, textures,
sounds or music. No third-party brands.

| Category | Assets | Source | Status |
|---|---|---|---|
| Vehicles | `Prefabs/Vehicles/{Excavator,DumpTruck,Bulldozer,RoadRoller}.prefab` | `VehicleBuilder` — procedural rounded meshes, custom crawler-track mesh | **Custom procedural models** (stylised, final for first release; can be swapped for artist models without code changes — gameplay only needs the named pivots) |
| Vehicle portraits, app icon | `Art/UI/Portraits/*.png`, `Art/UI/AppIcon.png` | `PortraitRenderer` renders the prefabs | Generated |
| Environment props | `Prefabs/Environment/*` (trees, bush, fence, flag, lamp, cloud, shed, water tower, windmill, 4 town houses, hopper, brick pallet, skip, barrier, sign post, soil mounds, resident, bunting, balloon arch, fountain) | `PropBuilder` | Custom procedural, toy style |
| Debris | `Prefabs/Activities/Debris{Rock,Log,Crate,Cone}.prefab` | `PropBuilder` | Custom procedural |
| House parts, roadworks patches, markers, guidance arrow | built into `ConstructionTown.unity` | `TownBuilder` | Custom procedural |
| Particles | `Prefabs/VFX/FX_{Sparkle,Confetti,Poof,Smoke}.prefab` | `PropBuilder` | Generated |
| Icons & UI shapes | `Art/UI/Icons/*.png` (~31) | `IconPainter` (SDF rasteriser `Canvas2D`) | Generated, final for first release |
| Textures | `Art/Textures/tex_{grass,sand,dirt,road,road_plain,track}.png` | `IconPainter` | Generated |
| Materials, meshes | `Art/Materials/*.mat`, `Art/Models/Meshes/*.asset` | `ArtLibrary` | Generated |
| Sound effects | `Audio/SFX/*.wav` (17 + engine loop) | `AudioSynth` (deterministic synthesis) | Generated, original; replaceable by a sound designer |
| Music | `Audio/Music/music_{menu,town}_loop.wav` | `AudioSynth` (original melody) | Generated, original |

## Reused code

`Canvas2D`, `EditorAssetUtil`, `AudioSynth` (editor) and `MeshFactory`, `Tween` (runtime) were adapted from the
owner's Little Burger World project (same author), namespaces changed.

## Temporary / placeholder

None of the shipped visuals are greybox placeholders. They are deliberately simple procedural models; a future
art pass could replace them with authored meshes using the same pivot names (`Body`, `Cab`, `Boom`, `Stick`,
`Bucket`, `BedPivot`, `Wheel`, `SteerPivot`, `Beacon`, `BubbleAnchor`).
